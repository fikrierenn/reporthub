### 4 Kritik Bugfix

**B-01 (data integrity) — `AiController.cs:446`**
- `s.CreatedObligationId = -1` placeholder kalıcı yazılıyordu, gerçek `ContractObligation.Id` asla cross-link edilmiyordu.
- **Fix:** Pair list pattern — ilk `SaveChangesAsync()` Obligation Id alır, ikinci `SaveChangesAsync()` ile `suggestion.CreatedObligationId = obligation.Id` set.
- Yorum + Plan 33 BUGFIX-1 referansı eklendi.

**B-02 (security) — `Views/Ai/Review.cshtml:126`**
- `src="/@Model.ContractFile.FilePath"` — wwwroot olmayan App_Data path'i 404 + path traversal riski.
- **Fix:** `@Url.Action("Download", "Contracts", new { id = Model.ContractFile.Id })` — auth + firma + path guard'li Download endpoint kullanılıyor (zaten mevcut).

**B-03 (CRITICAL security) — `DocumentsController.Upload` + `Index.cshtml:181`**
- `wwwroot/uploads/contracts/{firmaId}/{guid}.pdf` UseStaticFiles ile **auth bypass** — firma sınırı yok, dosya path'i tahmin edilince direkt erişim.
- **Fix 1:** Upload path `ContentRoot/App_Data/contracts/{firmaId}/` (ContractsController.UploadFile ile aynı konvansiyon, private storage).
- **Fix 2:** Path traversal guard (`Path.GetFullPath` + `StartsWith` check).
- **Fix 3:** Yeni `Documents/Download/{id}` endpoint — auth + firma + path guard, ContractsController.Download pattern reuse.
- **Fix 4:** `Index.cshtml` href doğrudan FilePath URL → `Url.Action("Download","Documents")`.

**B-04 (feature crash) — `WizardExtractionService.cs:113`**
- Taranmış PDF için `InvalidOperationException` fırlatıyordu ("JPEG/PNG olarak tarayın").
- **Fix:** `TesseractOcrExtractor` constructor'a inject + text<100 char fallback chain. OCR sonucu da yetersizse user-friendly hata. PDF→image vision fallback scope dışı (Plan 33 Faz 4 D2 altında).
