## Kararlar

### ADR-012 (yazılmış, dosya: `docs/ADR/012-pk-scheduler-firma-filter.md`)
3 mimari karar:
- PK tipi: **int** (Guid yerine — Mosaik core ile uyum)
- Background job: **IHostedService + Channel<int>** (Hangfire yerine — minimal dependency)
- Multi-tenant filter: **Session claim FirmaId** (EF Global Query Filter yerine)

### Çoklu firma erişimi: CSV (junction table değil)
- **Why:** "1,2,3 ya da hiç" 3-state needs; junction table over-engineering. CSV NVARCHAR(50) idempotent migration.
- **How to apply:** Yeni vNext modüllerinde firma scope filter `_currentUser.FirmaIds.Contains(entity.FirmaId)`.

### Periyodik yükümlülük: eager üretim (lazy değil)
- **Why:** BKMKİTAP sözleşmeleri 1-3 yıl, max ~60 obligation. IHostedService eklemenin maliyeti justifiye edilmez.
- **How to apply:** Sözleşme Save sırasında `ContractObligationGenerator.Generate()` tüm dönemleri üret, transaction ile kaydet.

### AI wizard pattern: tek sayfa Alpine + IMemoryCache + polling
- **Why:** Sticky session yok, multi-step state için hidden field en sade. Sync AI çağrısı UX bozar (3-15s freeze) → polling. Channel queue var ama wizard farklı path.
- **How to apply:** `IMemoryCache.Set("wizjob:" + jobId, status, 10min)` pattern'i diğer modüllerde de kullan (Document module'de OCR için aday).

### `[Required]+[BindNever]` çelişkisi (lesson)
- `[BindNever]` formdan binding yapmıyor AMA `[Required]` validation hâlâ çalışıyor → boş default'la fail. Çözüm: `[BindNever]` kullanılan field'larda `[Required]` kaldır, DB NOT NULL constraint güven.
- Non-nullable reference type (`Firma Firma { get; set; } = null!;`) implicit required üretiyor — `[ValidateNever]` ekle.

### Hatalar — kullanıcının uyarıları (zorunlu öğrenim)
- **Subagent/skill kullanmadım** (defansif kontrolleri atladım) → `code-reviewer` çoklu hatayı (PasswordHash, Firma nav, FirmaIds çakışma) yakalardı. Bundan sonra her POST handler değişikliğinde `code-reviewer` zorunlu.
- **Inline CSS spamı** → kullanıcı 2 kez uyardı. Plan 25 view'larında düzeltildi (form-section-card pattern'e geçildi). 30+ admin view'daki envanter borcu kalıyor.
- **Mimari kararı kullanıcıyla almadım** → FirmaId int → bool → multi → CSV evrimi 4 düzeltme aldı. `llm-council` veya `code-architect` ile öncesinde tartmalıydım. Bugün AI wizard için doğru yapıldı (code-architect blueprint çağrıldı).
