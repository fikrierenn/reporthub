### Faz C — AI Provider Chain (DikkatIQ port, **bu plan**) ⏳

**Hedef:** `Mosaik.Core.Ai` namespace'inde 3-layer fallback LLM altyapısı.

**Port edilecek dosyalar:**
1. `Mosaik.Core/Ai/ILlmService.cs` — DikkatIQ `ILlmService.cs` (CompleteAsync(prompt, schema?) → text/json)
2. `Mosaik.Core/Ai/Settings/LlmSettings.cs` — provider config (endpoint, model, apiKey, timeout)
3. `Mosaik.Core/Ai/Providers/OllamaLlmService.cs` — localhost:11434, Türkçe model (qwen2.5:3b CPU)
4. `Mosaik.Core/Ai/Providers/GeminiLlmService.cs` — Mscc.GenerativeAI 3.1.0
5. `Mosaik.Core/Ai/Providers/ClaudeLlmService.cs` — Anthropic.SDK 5.10.0
6. `Mosaik.Core/Ai/Providers/FallbackLlmService.cs` — chain orchestrator (timeout/error → next provider)
7. `Mosaik.Core/Ai/PromptEngine.cs` — prompt templating + system message + few-shot örnekleri
8. Mevcut `IAiSummaryProvider.cs` → `Mosaik.Core/Ai/Summarization/` altına taşı

**DI kayıt:** `services.AddMosaikAi(opts => opts.UseFallbackChain(...))`. Settings appsettings.json'dan veya AiSettings tablosundan (mevcut Plan 17 AiSettings).

**Test:** xUnit `FallbackLlmServiceTests` — Ollama down → Gemini fallback simülasyonu (mock).

**Effort:** ~4h.

### Faz D — Extraction Layer (DikkatIQ pdf+suggestion-approval, **bu plan**) ⏳

**Hedef:** PDF/dosya → AI extract → suggestion entity → kullanıcı review → onaylanırsa target entity oluştur.

**Port edilecek dosyalar:**
1. `Mosaik.Core/Ai/Extraction/IPdfTextExtractor.cs` — DikkatIQ `IPdfTextExtractor.cs`
2. `Mosaik.Core/Ai/Extraction/PdfPigTextExtractor.cs` — UglyToad.PdfPig + OCR fallback (OCRmyPDF CLI Türkçe)
3. `Mosaik.Core/Ai/Extraction/IAiExtractionService.cs` — generic extract orchestrator
4. `Mosaik.Core/Ai/Extraction/AiExtractionService.cs` — pipeline: PDF → text → 2-stage prompt → JSON → AiSuggestion insert
5. `Mosaik.Core/Ai/Suggestion/AiSuggestion.cs` — generic suggestion entity (TargetEntityType + TargetEntityId + JsonPayload + Status)
6. `Mosaik.Core/Ai/Suggestion/IAiSuggestionService.cs` — list/approve/reject
7. `Mosaik.Core/Ai/Prompts/PromptBase.cs` — Türkçe prompt template
8. Migration 42: `dbo.AiSuggestions` tablo (cross-modül)

**Pattern:** AI **asla doğrudan yazmaz** — hep AiSuggestion → review → approve. Plan 25 Sözleşme'de `AiSuggestion(targetEntity="Contract", payload={...})` insert, admin Pages/AI/Index.cshtml'de görür, onaylar → ContractService.CreateAsync.

**Test:** xUnit `AiExtractionServiceTests` (mock LLM), `PdfPigTextExtractorTests` (sample PDF).

**Effort:** ~3h. PdfPig + OCRmyPDF setup ekstra (~1h).

### Kapsam dışı (Plan 19/25/26 sırasında ele alınır)

## 3. Alternatifler (5 lens)

🔴 **Contrarian:** "Mosaik.Core.Ai gereksiz — her modül kendi LLM çağrısını yapsın." Hayır, 3 farklı modülün 3 farklı şekilde Gemini auth yapması = 3x maliyet + tutarsızlık. Shared kit zorunlu.

🔵 **First Principles:** Asıl soru "AI nasıl güvenle Mosaik içine girer?" — cevap: **suggestion-approval pattern**. Direkt yazma yok, hep önerip kullanıcı onayı bekleyecek. DikkatIQ tam bunu yapıyor, port en güvenli yol.

🟢 **Expansionist:** "AI Core olunca neden sadece DikkatIQ pattern'i? Daha geniş abstraction (vector DB, RAG) gerek mi?" Plan 16.5 scope'u dar tutalım — Plan 26 NL-to-SQL ve Plan 19 Doküman semantic search kendi planlarında tartışılır.

⚪ **Outsider:** "Niye Anthropic.SDK + Gemini SDK ayrı? Tek HTTP wrapper olmaz mı?" Olabilir ama 1) DikkatIQ kanıtlanmış 2) SDK'lar response parsing/error handling sağlar 3) cloud provider değiştirmeden kullanmak istesek bile tek HTTP wrapper bakım yükü.

🟡 **Executor:** İlk adım — DikkatIQ'in `Mosaik.Core/Ai/` altına klasör kopyala (LLM services + settings + interfaces). 30 dakika içinde compile edilebilir base. Sonra DI registration.

## 4. Riskler

| Risk | Etki | Olasılık | Mitigation |
|---|---|---|---|
| Ollama localhost erişimi olmayan server'da Faz C kırılır | yüksek | düşük | Settings'te `EnableLocal=false` → Gemini'ye fallback. AiSettings.cshtml'de ayarlanabilir |
| OCRmyPDF CLI Windows'ta sorunlu (Tesseract Türkçe pack kurulum) | orta | orta | Optional dependency. Yüklü değilse PdfPig text-only extraction (taranmış PDF eksik kalır, log warning) |
| Mscc.GenerativeAI veya Anthropic.SDK breaking change | orta | düşük | DikkatIQ'in çalışan versiyonlarını lock et (NuGet lockfile) |
| Cross-modül `AiSuggestion` entity migrate edilirken modül-içi suggestion var (Plan 17 yok ama Plan 19 başlatınca olabilir) | orta | düşük | Migration 42'den önce Plan 19 başlamasın. Plan ordering doğru |
| LLM API key güvenliği — appsettings.json'da plain text | yüksek | yüksek | AiSettings tablosuna şifreli kayıt (Plan 17 Faz F'de zaten encrypted) — Faz C'de aynı pattern devam |
| Maliyet kontrolü — Gemini API ücretli | yüksek | yüksek | Per-modül cache (24h TTL), prompt caching, model selection (haiku/flash önce) |
