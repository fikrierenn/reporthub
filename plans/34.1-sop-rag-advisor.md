## 1. Problem

Plan 34 Faz F orijinal scope "single-SOP chat MVP" yetersiz:

- BKM 27+ SOP, kullanıcı **tek SOP'ta** takılmaz — "izin nereye verilir?", "fazla mesai onayı kim?", "yıllık izin maksimum kaç gün?" gibi **cross-SOP** sorular sorar.
- AI tek bir SOP'a bağlı kalırsa cevap eksik veya yanıltıcı.

## 2. Scope

### Dahil

**AI Stack (Aday A — agent raporu TL;DR):**
- LLM: **Qwen 2.5 3B Instruct** GGUF Q4_K_M (~2.0 GB), Apache 2.0
- Runtime: **LLamaSharp 0.27** (MIT, llama.cpp .NET binding) — in-process
- Embed: **intfloat/multilingual-e5-base** ONNX INT8 (~110 MB) + `Microsoft.ML.OnnxRuntime`
- Abstraction: **Microsoft.Extensions.AI** `IChatClient` (Phi/Qwen swap maliyeti 0)
- Toplam RAM ~3.5 GB (BKM 8GB+ laptopta rahat)

**RAG pipeline:**
- `SopChunk` entity (SopVersionId, ChunkOrder, Content, EmbeddingJson)
- Chunker: 512-token chunks + 64 overlap, PlainTextContent kaynağı
- Indexer: yeni Approved version → chunks → embed → persist (Hangfire enqueue)
- Retrieval: cosine similarity in-memory + top-K=4 + min similarity 0.5
- Context build: top-K chunk + SOP başlık + version numarası

**Inference:**
- `SopRagAdvisorService` (question → embed → retrieve → context → LLM → parse + persist)
- `ILlmRunner` abstraction (LLamaSharp impl)
- System prompt sıkı: "Yalnızca verilen SOP kaynaklarına bağlı kal. Bilgi yoksa 'Bu soruya cevap verecek SOP bulunamadı' de + Plan 29 görev oluştur."
- Background warm-up `IHostedService` — cold start gizler

**UI:**
- Yeni sayfa: `/SOP/Advisor` ("Prosedür AI'sına Sor") — sidebar entry
- Alpine chat UI + soru kutusu + son 10 history
- KVKK uyarı banner üst + "AI önerisi — yöneticinize danışın" disclaimer alt
- Cevap altında **"Kaynaklar: [SOP-1] [SOP-2] [SOP-3]"** (top-3 link + similarity score)
- SOP detay sayfasından da link "Bu SOP hakkında AI'ya sor" — context preselect

**Persistence + audit:**
- `SopAiConversation` (UserId, Question, Answer, TokensUsed, UserFeedback enum, FeedbackNote, SourceSopVersionIds CSV, CreatedAt)
- Her soru-cevap audit log (`sop_ai_question_asked`)
- Thumbs-up/down feedback endpoint (POST `/SOP/Advisor/Feedback/{conversationId}`)
- Admin dashboard: "thumbs-down listesi" → SOP içerik iyileştirme sinyali

**Rate limit:**
- 20 soru/saat/kullanıcı (`SopAiConversation` count'tan)
- Admin bypass

**Retention:**
- 1-yıl Hangfire cron `sop-ai-history-cleanup` daily 03:00 Turkey
- KVKK uyumlu (audit log ana kaydı 5-yıl ayrı)

**Fine-tune pipeline (Python, ayrı süreç):**
- `scripts/ai-train/sop-finetune.ipynb` (Unsloth + QLoRA + Colab T4)
- `scripts/ai-train/export-gguf.py` (`llama.cpp convert_lora_to_gguf.py` wrapper)
- LoRA adapter `App_Data/models/lora/sop-vYYYY-MM.gguf` (~50 MB)
- LLamaSharp `--lora` flag ile runtime swap (merge ETME — llama.cpp issue #7062)
- Sentetik QA üretimi: admin sayfa "QA Üret" → Groq/Gemini ile 5-10 QA per SOP → insan review → JSONL export

**Cloud fallback (opt-in):**
- `SopAiSettings.UseCloudFallback` default OFF
- ON ise local fail → Groq/Gemini → yine fail → "AI erişilemez"
- KVKK toggle admin UI'da net

## 3. 5 lens

🔴 **Contrarian:** Local LLM (Qwen 2.5 3B Q4) kalitesi BKM SOP cevaplarına yetmezse? **Cevap:** Cloud opt-in fallback (Groq/Gemini), KVKK toggle admin'de. Performans tatmin değilse v2: GPU sunucu (RTX 4060 ~$1000) + Trendyol-7B (TR'de daha güçlü). Kararlı upgrade yolu.

🔵 **First Principles:** Gerçek değer "prosedür sorusuna doğru cevap". **RAG ana motor** (corpus güncel kalır), fine-tune **sadece tarz + domain jargon**. Fine-tune önce yapmak yanlış — 50 SOP yetersiz, sentetik QA gerekli. RAG ilk gün çalışır, fine-tune ay 1-2'den sonra anlamlı.

🟢 **Expansionist:** Aynı stack Documents Plan 27 Faz E'de kullanılır. `Mosaik.Core.AI.Embed` + `Mosaik.Core.AI.Local` shared kit yarın Documents için reuse. Bu plan iki proje birden açar.

⚪ **Outsider:** "Niye Ollama değil?" Ollama IPC overhead + ayrı process + dep + Windows servisi yönetimi. LLamaSharp in-process direkt mmap → 0 IPC, 0 ekstra service. Deployment basitleşir. Kullanıcı kararı (Ollama yasak) bu mantığa uyar.

🟡 **Executor:** Pazartesi sabahı 09:00:
1. `dotnet add package LLamaSharp + LLamaSharp.Backend.Cpu`
2. Qwen GGUF indir manuel `App_Data/models/llm/`
3. Smoke test: `var output = await runner.InferAsync("Türkçe merhaba")` console'da yeşil
4. İlk commit: `feat(sop-advisor): Faz 0 stack scaffold (plan: 34.1)`

## 4. Alternatifler

### A) Ollama + REST API
**Reddetme:** Kullanıcı şartı ("Ollama bağımlılığı yasak"). Ek process + IPC + Windows servisi yönetimi.

### B) Cloud-only (Groq/Gemini default)
**Reddetme:** KVKK risk (prosedür içeriği yurt dışı). BKM Kitap → KVKK envanteri uyumlu değil. Maliyet patlama riski. Opt-in fallback OK ama default OFF.

### C) Embed cloud + LLM local
**Reddetme:** Yarı KVKK risk (soru cloud'a gider). Tutarsız.

### D) Tam-local Qwen 2.5 3B + e5-base + LLamaSharp (SEÇİLEN)
**Sebep:** Agent araştırması TL;DR Aday A. KVKK temiz, lisans Apache 2.0 + MIT, BKM laptopta CPU çalışır, fine-tune Colab ücretsiz T4 yeterli, Documents'a reuse path.

### E) Phi-3.5-mini-instruct + ONNX Runtime GenAI
**Reddetme (ikinci sıra):** TR var (multilingual MMLU 55.4 — iyi), MIT lisans en temiz, Microsoft official. Ama Qwen TR fine-tune ekosistem (Unsloth Qwen resmi pipeline) daha güçlü, Türkçe topluluk daha aktif. Plan B fallback olarak kal.

## 5. Riskler

| Risk | Etki | Olasılık | Mitigation |
|---|---|---|---|
| CPU latency 15-30 sn — kullanıcı tahammül eşiği aşar | yüksek | orta | Background warm-up + 1.5B fallback opsiyon + GPU sunucu v2 upgrade path |
| Hallucination — local 3B model RAG'sız çöker | yüksek | yüksek | Sıkı RAG (top-K=4 + threshold 0.5) + system prompt "kaynak yetersiz → cevap verme" + Plan 29 task pattern |
| 50 SOP corpus yetersiz — fine-tune anlamsız | orta | yüksek | Sentetik QA augmentation (Groq/Gemini, insan review). Ay 3+ thumbs feedback DPO sinyal. |
| LoRA merge bug (llama.cpp issue #7062) | orta | düşük | Merge ETME — runtime `--lora` flag ile uygula. LLamaSharp `ModelParams.LoraAdapters` koleksiyonu. |
| BKM proxy → HF Hub download yok | orta | yüksek | MSI / installer pre-bundle. `App_Data/models/` shipping. Runtime download trial flag (opsiyonel). |
| Kurumsal laptop RAM 8GB sınır | orta | orta | Footprint ~3.5GB ölçüldü. 4GB üstü olursa 1.5B'ye düş. Concurrency tek-worker queue. |
| LLamaSharp .NET 10 forward-compat | düşük | düşük | Resmi target net8 — smoke test şart. Multi-target `net8.0;net10.0` fallback hazır. |
| Türkçe kalite Qwen 2.5 3B yetersiz | orta | orta | Trendyol-LLM-7B-chat-v4.1.0 (~4 GB Q4) — RAM yeterse upgrade. v2 ADR'de yol. |
| Fine-tune Colab T4 ücretsiz kota | düşük | orta | RunPod $0.20-0.40/h fallback. Ayda 1 train ~$0.50. |
| Cloud fallback sızıntı | yüksek | düşük | Default OFF + admin UI net toggle + audit `sop_advisor_cloud_used` + KVKK envanter notu |
| Audit + chat history KVKK ihlal (kişi adı, TC yazılır) | yüksek | orta | KVKK banner üst, regex filter, audit log + admin görür. Plan 40 envanter entegrasyon. |
