## 1. Problem

Plan 33 ile Mosaik admin view'larının 12'si standardize edildi (inline=0). **Tek istisna kaldı:** V2 Dashboard Builder.

- `Mosaik/Views/Admin/CreateReportV2.cshtml` — 967 satır, **81 inline-style**
- `Mosaik/Views/Admin/EditReportV2.cshtml` — 1067 satır, **97 inline-style**

İkisi neredeyse identical (sadece data load + title farkı). V2 canonical (V1 silindi, eski URL'ler V2'ye redirect). Refactor zorlukları:

- **Canvas + drawer + query builder** (qb) widget UI — kendine özgü pattern, Form A pattern (form-section-card) uygulanamaz
- **GridStack** drag-drop canvas — boyut/pozisyon stilleri runtime hesaplanır
- **Chart.js preview** — designer ↔ Run görsel parite (M-11 F-09)
- **Alpine.js drawer state** — `rsPanelOpen` toggle, dirty chip, beforeunload
- **Inline tek-kullanımlık stiller:** `width:130px`, `height:22px`, `font-size:10px` gibi widget-specific ölçüler — utility'ye uymaz

## 2. Scope

### Kapsam dahili
- Inline'ların 3 kategoriye ayrılması:
  1. **Düz utility'ye çevrilebilir (~60%):** `style="margin-right:8px"` → `.icon-mr`, `style="font-size:10px"` → `.text-xs`, paper card inline → `form-section-card.wide` (uyduğu yerlerde)
  2. **Widget-specific utility eklenmeli (~30%):** Query Builder satırları (`.qb-row`, `.qb-cell`, `.qb-input-narrow`), drawer panel header'ları, result-set preview tablo — builder-v2.css'e yeni `.builder-*` namespace
  3. **Runtime/dynamic style (~10%):** GridStack data-driven width/height, Chart.js canvas — bunlar **inline kalır** (`style="--w: 4"` gibi CSS var pattern veya `data-*` attribute + JS)
- `builder-v2.css` (mevcut) — yeni `.builder-*` utility paketi ~30-40 sınıf
- Smoke test: Create + Edit + GridStack drag + Chart preview + ResultSet preview + Drawer open/close + Save (dirty chip + beforeunload)

### Kapsam dışı
- Canvas/builder mantık değişikliği
- Yeni widget tipi
- ViewModel veya Controller refactor
- M-11 F-7+ scope (yeni feature)

### Etkilenen dosyalar
- `Mosaik/Views/Admin/CreateReportV2.cshtml` (967 → ~600-700 beklenen)
- `Mosaik/Views/Admin/EditReportV2.cshtml` (1067 → ~700-800 beklenen)
- `Mosaik/wwwroot/assets/css/builder-v2.css` (mevcut, ~30-40 utility ekle)

**Tahmini boyut:** 3 dosya / ~120 satır CSS ekleme + ~200 satır view temizliği. Tier 3.

**Reddetme sebebi:** Plan 23 inline-style yasağı (sıfır tolerans). Tutarsızlık tehlikeli — yeni geliştirici alışkanlığı kötüleştirir.

## 4. Riskler

| Risk | Etki | Olasılık | Mitigation |
|---|---|---|---|
| GridStack drag-drop bozulur (CSS specifik selector etkilenir) | yüksek | orta | GridStack CDN class'larına dokunma; sadece view-içi inline'lara dokun |
| Chart.js preview canvas size kırılır | yüksek | orta | Chart container width/height **runtime hesaplanır** — bu inline'lar kalır |
| Drawer/qb panel layout bozulur | orta | yüksek | Önce/sonra screenshot karşılaştırması (preview_screenshot) |
| Dirty chip + beforeunload Alpine binding kırılır | yüksek | düşük | `x-data` + `@@input` JS davranışı korunur, sadece HTML attribute |
| Agent yüzeysel — widget-specific inline'ları utility yerine `display:contents` istisnasına alır | orta | orta | Agent prompt'ta açıkça "qb/drawer widget'ı için yeni `.builder-*` utility ekle, inline bırakma" |
| Builder save logic etkilenir | yüksek | düşük | Sadece HTML render katmanı, controller/JS dokunulmaz |
