### Faz 2 — API Key Encryption (HIGH, ~3-4h)

**Hedef:** z.ai / Groq / Gemini API key'leri DB'de plaintext durmaz, ASP.NET Core `IDataProtector` ile encrypt at rest.

**Adımlar:**
1. `Mosaik.Services.Ai.AiSettingsProvider` içine `IDataProtector` inject et (`"AiSettings.ApiKey"` purpose)
2. `AdminController.AiSettings` POST handler'ında `Protect()` ile encrypt → DB
3. `AiSettingsProvider.GetActiveOrderedAsync` içinde `Unprotect()` ile decrypt → memory'de plaintext
4. Audit log `NewValuesJson` serialize sırasında `ApiKey` field'ını `null` yap (sızıntı önlemi)
5. Migration NN — mevcut DB'deki plaintext key'leri admin'e re-input ettirmek için "ApiKey null" set + admin GUI'de "key boş, lütfen yeniden girin" uyarısı

**Done:** Tüm AI provider testleri (Plan 17 Faz F) yeşil, AdminController.AiSettings smoke test (yeni key encrypt → decrypt çalışıyor).

**Alternatif (reddedildi):** Azure Key Vault — kurumsal AD/secret yönetim altyapısı yok, dev maliyet yüksek. User Secrets — prod'da çalışmaz. Data Protection en pragmatik.

### Faz 5 — Wizard Queue Migration (HIGH büyük, ~3-4h)

**Hedef:** `WizardExtractionService.Start` fire-and-forget `Task.Run` pattern'ini kaldır, mevcut `AiPipelineQueue + AiExtractionWorker` altyapısına entegre et.

**Adımlar:**
1. `WizardExtractionJob` table veya mevcut `ContractAiExtraction` extend (status = `WizardPending` | `WizardProcessing` | `WizardDone` | `WizardFailed` enum eklemesi)
2. `WizardExtractionService.Start(int contractFileId)` API değişikliği:
   - DB'ye job kaydı (status=Pending)
   - Queue'ya enqueue
   - jobId döner
3. `AiExtractionWorker.ProcessAsync` veya yeni `WizardExtractionWorker` background service — worker DB'den state okur, AppDomain shutdown'da `Pending` kalır (sonraki başlangıçta resume).
4. `GetStatus(jobId)` DB'den status okur (IMemoryCache yerine).

**Alternatif (kabul edilebilir):** `IHostApplicationLifetime.ApplicationStopping` token'ını mevcut `Task.Run`'a geçirmek minimum effort. AppDomain shutdown sırasında `OperationCanceledException` → cache'e `Done=true, Error="..."` yazılır. Multi-instance hâlâ sorun ama ReportHub Mosaik tek instance dev/prod (Hangfire zaten tek server).
