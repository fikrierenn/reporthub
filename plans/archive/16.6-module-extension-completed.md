## 4. IMosaikModule interface

```csharp
namespace Mosaik.Core.Module
{
    public interface IMosaikModule
    {
        // Plan 12 AppModule.ModuleKey ile eşleşir (DB-driven enable/disable)
        string ModuleKey { get; }

        // Sidebar/menü için (Plan 12)
        string DisplayName { get; }
        string? Icon { get; }            // Font Awesome class
        int DisplayOrder { get; }

        // DI kayıtları (services.AddScoped, AddSingleton, vs.)
        void ConfigureServices(IServiceCollection services);

        // EF DbSet konfigürasyonu (modelBuilder.Entity<X>(...))
        void ConfigureModelBuilder(ModelBuilder modelBuilder);

        // Migration script klasörü (Database/35_*.sql gibi)
        // ModuleLoader bu klasörden script'leri sırayla bulup uygular
        // (sql-migration-writer skill formatı)
        string? MigrationFolder { get; }

        // Endpoint mapping (app.MapControllerRoute, app.MapGet, vs.)
        // Şimdilik default MVC route Areas pattern'i ile çalışır,
        // gerekirse modül kendi route'unu burada tanımlayabilir.
        void MapEndpoints(IEndpointRouteBuilder endpoints);
    }
}
```

## 5. ModuleLoader

```csharp
public static class ModuleLoader
{
    private static List<IMosaikModule>? _cached;

    public static IReadOnlyList<IMosaikModule> DiscoverModules()
    {
        if (_cached != null) return _cached;

        // Mosaik.Modules.* assembly'lerini tara
        var modules = AppDomain.CurrentDomain.GetAssemblies()
            .Where(a => a.GetName().Name?.StartsWith("Mosaik.Modules.") == true)
            .SelectMany(a => a.GetTypes())
            .Where(t => typeof(IMosaikModule).IsAssignableFrom(t)
                     && !t.IsInterface && !t.IsAbstract)
            .Select(t => (IMosaikModule)Activator.CreateInstance(t)!)
            .OrderBy(m => m.DisplayOrder)
            .ToList();

        _cached = modules;
        return modules;
    }

    public static void RegisterAll(IServiceCollection services)
    {
        foreach (var m in DiscoverModules()) m.ConfigureServices(services);
    }

    public static void ApplyToModelBuilder(ModelBuilder mb)
    {
        foreach (var m in DiscoverModules()) m.ConfigureModelBuilder(mb);
    }

    public static void MapAll(IEndpointRouteBuilder endpoints)
    {
        foreach (var m in DiscoverModules()) m.MapEndpoints(endpoints);
    }
}
```

`Mosaik/Program.cs`:
```csharp
ModuleLoader.RegisterAll(builder.Services);
// ... diğer config
app.MapControllerRoute(...);  // mevcut legacy
ModuleLoader.MapAll(app);     // modüllerin endpoint'leri
```

`MosaikContext.OnModelCreating`:
```csharp
ModuleLoader.ApplyToModelBuilder(modelBuilder);  // her modül kendi DbSet'ini yapılandırır
```

## 9. Geri uyumluluk + risk

- **Mevcut 273 test:** Mosaik.Core split sırasında namespace import'ları kontrol edilir. Test ana projeyi referans aldığı için kırılmaz (umulan).
- **Migration sırası:** Her modül kendi `Database/NN_*.sql` numaralandırmasını yapar. Çakışma riski var — `Mosaik.Modules.Tamim/Database/` klasöründe migration NN'leri Tamim-içi sıra (1, 2, 3...), ana Mosaik migration'ları (01-34) etkilenmez. ModuleLoader uygulama sırasını her modül için ayrı yönetir.
- **EF migration tooling:** EF Core migrations bu projede kullanılmıyor (Plan M-06 backlog). Manuel SQL script'leri zaten ayrı klasörlerde sürdürülebilir.
- **Test izolasyonu:** Modül başına `Mosaik.Modules.Tamim.Tests` csproj eklenebilir, opsiyonel.
- **DI conflict:** İki modül aynı interface için farklı impl kayıt etse — son kayıt kazanır (ASP.NET default). Convention: her modül sadece kendi tip'lerini kayıt eder.
- **DB-side enable/disable:** `AppModule.IsActive=false` ise modül endpoint'leri 404 dönmeli. Middleware ile gerçeklenir (Faz B5'te ekleyebiliriz veya Plan 16.6.5'e ertelenir).
