# Plan 16.5 — Mosaik.Core Shared Kit

**Durum:** Taslak — kullanıcı onayı bekliyor
**Tier:** 3 (yeni proje + 7+ modülü etkiler + namespace mimarisi)
**Tarih:** 2026-05-07
**Önceki bağlam:** Plan 16 (vNext modül roadmap) keşfi sonrası — 9 vNext modülü (Plan 17-25 + 26) ortak pattern'lere ihtiyaç duyuyor. Ayrı ayrı yazılırsa drift + duplicate maliyet. Bu plan, downstream maliyeti düşüren paylaşımlı kütüphaneyi tanımlar.

---

## 1. Problem

Plan 16 vNext roadmap'i 9 modül (17-25, 26) içeriyor. Tüm modüllere ortak olan 12+ pattern var (BaseEntity, ServiceResult, Lookup, Workflow, Attachment, ReadLog, AI providers, prompt engine, vs.). Her modül kendi versiyonunu yazarsa:

- **Drift:** 9 farklı `BaseEntity`, 9 farklı audit pattern'i
- **Duplicate maliyet:** Her modülde ~3-5 saat boilerplate
- **Test gap:** Her modül kendi pattern'ini test etmek zorunda
- **Refactor cehennemi:** Plan 14 Faz C `IUserDataScope` 9 yerde aynı şekilde implement edilemez

Plan 17 (Tamim) başlamadan önce shared kit kurulursa downstream 9 modülün her biri **~3 saat tasarruf** sağlar = ~27 saat toplam.

## 2. Scope

**Kapsam içi:**
- `Mosaik.Core/` projesi (yeni .csproj veya namespace, `Mosaik/` içinde alt-klasör)
- 4 alt-katman: Domain primitives, AI Core, Workflow primitives, Filter scope
- DikkatIQ AI layer port (PDF + suggestion-approval)
- YonetIQ AI Core port (multi-provider + prompt engine + conversation context + learning signal)
- YonetIQ domain pattern'leri (ServiceResult, Lookup, Approval, SourceTraceable)
- Operax pattern'leri (DictionaryType/Value + StatusTransition + EventQueue konsepti)
- Plan 14 Faz C `IUserDataScope` interface (Plan 14 ile birleşir)

**Kapsam dışı:**
- Modül implementasyonu (Plan 17+ alt-planlarda)
- UI bileşenleri (her modülün kendi Razor view'ları)
- DB migration'ları (her modülün kendi migration'ı, sadece shared entity'ler için 1 migration)

## 4. Faz Planı

### Faz A — Domain Primitives + Workflow (~4 saat)

**A1. `BaseEntity.cs`** (YonetIQ pattern):
```csharp
public abstract class BaseEntity {
    public DateTime CreatedAt { get; set; } = DateTime.UtcNow;
    public string? CreatedBy { get; set; }
    public DateTime? UpdatedAt { get; set; }
    public string? UpdatedBy { get; set; }
}
public abstract class BaseEntity<TKey> : BaseEntity { public TKey Id { get; set; } = default!; }
```

**A2. `ISoftDeletable`, `IAuditable`, `ISourceTraceable`** marker interface'leri.

**A3. `ServiceResult<T>`** (YonetIQ port + güvenli mesaj):
- `IsSuccess`, `Data`, `Message`, `ErrorCode`
- `BaseService.cs` `ex.Message` expose'u **port edilirken düzelt** — generic mesaj + logger.LogError
- security-principles.md #7 uyumlu

**A4. `IWorkflow<TStatus>` + `StatusTransition`** (Operax pattern + YonetIQ ApprovalRequest birleşimi):
- Generic state machine
- `IsAllowed(TStatus from, TStatus to, string[] roles)` kontrolü
- DB-driven `StatusTransitions` tablosu

**A5. `ApprovalRequest` + `ApprovalStep` + `ApprovalService`** (YonetIQ port):
- `EntityType + EntityId` generic
- `StepOrder` bazlı sıralı onay
- `MIN(StepOrder)` sıradaki onayçı
- Plan 23 Onay/E-imza modülünün temeli

**A6. Migration:**
- `33_CreateMosaikCore.sql` — `DictionaryType`, `DictionaryValue`, `StatusTransitions`, `ApprovalRequests`, `ApprovalSteps`, `Attachments`, `ReadLogs`

**Done criteria:**
- [ ] `Mosaik.Core/Domain/` + `Workflow/` dolu

## 7. Alternatifler (5 Lens)

- 🔴 **Contrarian:** "Shared kit yazma, her modül kendi versiyonunu yazsın." Geçerli — solo dev için 18h yatırım büyük. Ama 9 modül × 3h tasarruf = 27h, ROI pozitif. Ayrıca drift maliyeti hesaba katılmamış.
- 🔵 **First Principles:** "Hangi pattern gerçekten 3+ modülde kullanılacak?" Cevap: BaseEntity (9), Lookup (5), Workflow/Approval (5), AI Core (6), DataScope (4). Hepsi eşik üstü.
- 🟢 **Expansionist:** "Mosaik.Core'u NuGet paketi yap, başka projeler de kullansın." Premature — şimdi sadece Mosaik kullanır. Plan 30+ değerlendirilir.
- ⚪ **Outsider:** "9 modül için ortak kit yazmak büyük taahhüt — gerçekten 9 modülü yazacak mıyız?" Haklı. Plan 16.5'u **opt-in** yap: Plan 17 (Tamim) shared kit'siz başlasa da olur. Ama AI Core (Plan 16.5 Faz C) Plan 17 AI özet için lazım. **Karar:** Faz A+B yap (domain + workflow + lookup + dataScope), Faz C+D Plan 19'a kadar ertele.
- 🟡 **Executor:** "Pazartesi ne yaparız?" Plan 14 Faz A bitince Plan 16.5 Faz A başla. ~4h Faz A'nın somut çıktısı: BaseEntity + ServiceResult + 1 migration. Test edilebilir, geri dönülebilir.
